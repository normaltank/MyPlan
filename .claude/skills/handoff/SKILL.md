# Prepare a handoff

Summarize the user objective, accepted decisions, current checkout and commit, owned and unrelated changes, actual checks, evidence locations, unresolved questions and next step. Reference existing issues, PRs, plans and artifacts instead of copying their content.

Use the task's existing handoff or working-artifact location. If the recipient is on another machine, ensure required evidence is in an accessible authorized location; a temporary path on this computer alone is not a completed cross-agent handoff. Do not create a new permanent project guide for each session.

Redact secrets and unnecessary personal data. Suggest a skill only when the next concrete step needs it. Preparing this summary does not itself authorize sending it to another chat, contacting a colleague or launching a new agent.
