# Continue, compact or hand off

Use the current host's supported session controls. Keep working in the current session while it has the necessary context; automatic compaction is a continuation, not a reason to restart the task.

Before a handoff or context transition, preserve the current user objective, accepted decisions, current commit and checkout, owned versus unrelated changes, completed checks, evidence locations and the next unresolved step. Link durable primary evidence rather than relying on a prose summary alone.

A handoff is useful when another authorized agent, host or workspace needs to continue. The recipient must be able to access the referenced material. Delegate only within the current task's authorization and available host capabilities; a portable summary does not itself authorize sending a message or starting another task.

Do not infer a universal safe context size or require a particular slash command. Tool support and context limits vary by host. Choose a transition that preserves the work and follow any user request to pause, resume or change direction.
