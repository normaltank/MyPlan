本工单附有同事整理的师资链接（见下方“给定链接”）。这些链接只是线索，不等于已核实的名录。本阶段核对这些链接，不在全站另行搜索：
1. 用 browser_survey 一次打开给定链接（每次最多 8 个，超出分批），依据返回的 page 摘要、page.people（人名链接数、顿号名单人数、邮箱数、图片数）和新链接判断每个链接的性质，不必逐个 navigate 或用 browser_evaluate 读正文。
2. 只提交真正承载本学院在职专任教师名单的页面：教师名录，按职称、系所、学科分开的名单页，导师名录（仅当其中可能有主名录里没有的人），以及正文里依次平铺多位教师的文章页。
3. 不提交：只有文字介绍、没有人员名单的队伍概况或师资简介页；行政、党政、辅导员、实验技术、教辅人员名单；退休或曾执教名单；打不开、跳转到其他学院或其他学校的链接。名师风采、导师风采、人物专栏、教学团队等展示页，只有当其中确有主名录里没有的在职教师时才提交。
4. 给定链接若只是目录页（链接到几张子名单），打开子名单并提交子名单页；不要同时提交目录页和它的子名单。
5. 给定链接都不是教师名录时，才从学院主页核实一次师资栏目，找到真正的名录后提交；仍须在真实浏览器中打开核实。
提交时 branches 只含最终确认的名录 URL，与平时一样不附加说明或教师数据。
