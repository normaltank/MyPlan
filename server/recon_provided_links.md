本工单附有同事整理的师资链接（见下方“给定链接”）。这些链接是优先入口，不等于已核实的名录，也不限定本学院的全部采集范围。先核对给定链接，再检查学院官网是否还有遗漏的师资分支：
1. 用 browser_survey 一次打开给定链接（每次最多 8 个，超出分批），依据返回的 page 摘要、page.people（人名链接数、顿号名单人数、邮箱数、图片数）和新链接判断每个链接的性质，不必逐个 navigate 或用 browser_evaluate 读正文。
2. 给定页正文为图片、DOM 没有对应文字时，先打开该页并用 browser_read_image 读取实际正文原图，按 nextOffset 读完，再判断来源性质；不能因文字为空跳过图片，也不能把机构/行政表自动当教师名录。只提交真正承载本学院师资名单的页面：教师名录，按职称、系所、学科或师资类别分开的名单页，可能补充主名录范围的导师名录，以及正文里依次平铺多位教师的文章页。官网明确列为本学院师资的兼职、外聘等人员均在范围内，不限专任教师。
3. 不作为活跃采集分支：只有文字介绍、没有人员名单的队伍概况或师资简介页；只有行政事务、新闻、校友或讲座嘉宾内容且没有本学院师资身份依据的名单；打不开或实际承载其他学校、其他学院名单的链接。名师风采、导师风采、人物专栏、教学团队等展示页须核实其本学院师资身份及是否补充名录范围，不能仅凭栏目名称认定合格。身份或归属仍不明确时保留证据供后续复核，不自行猜定，也不仅凭同名认定重复。
4. 给定链接若只是目录页（链接到几张子名单），打开子名单并提交子名单页；不要同时提交目录页和它的子名单。
5. 无论给定链接是否有效，都从学院入口检查相关师资、导师、系所/教研室及不同师资类别导航；按 nextOffset 查看相关范围，对照已经核实的分支，补充遗漏的官方名录。已经核实的同一页面不重复打开，不扩展到无关学校、学院或历史新闻。
6. 给定链接全部失效时，仍从学院入口按上述流程发现真实名录。找不到名录或采集为零不能自动判定学院无师资，需保留失败证据供人工核验。
给定链接仍须执行 browser_verify_source：提交URL、source_role受控枚举及完整source_container_selector、实际role_evidence_selector、独立学院source_context_selector；角色声明不能替代当前浏览器用途/学院关系证明。只有组织成员关系或用途不明确的相关人员来源作为辅助/未知保留，不能全局标成师资，也不按标题关键词删除候选。提交结构字段须与本阶段工具成功参数一致，正文/原件及其SHA由工具保存，不写教师字段或引用进plan。给定教授介绍页只是一个已观察分支，仍核查其它官方师资分支与未知范围，不能把五条人物展示记录当全院人数。

source_context_selector允许逗号组合同一已访问页面的学校品牌与学院页头/导航/页脚身份，不要求两者在同一子树；须真实读取每个区域并共同绑定当前URL/HTML。教师履历中的学校名称不能代替机构branding，主标题用途与完整正文证明仍须独立通过。

给定或known_urls来源未进入活跃branches时，必须以source_dispositions保留实际访问处置：source_unreadable（实际打不开/HTTP错误）、source_structure_unresolved（已打开但名单结构未解）、source_relationship_unverified（可读但师资关系未知）、not_faculty_roster（正向组织用途与目标branding已证）。后两项附四个来源字段并执行browser_verify_source；未知用unverified_people_source，已证组织用途用organizational_membership。不能用词表未命中或任意role声明删来源。零活跃branches必须有处置记录，仍待核而非自动无师资。模型只输出URL、固定reason及结构选择器，原文与SHA由工具/worker保存；资格/结构未知不等于官网故障。
