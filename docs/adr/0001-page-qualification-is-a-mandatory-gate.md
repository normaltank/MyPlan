# Page qualification is a mandatory deterministic gate

Every GUI, CLI, discovery, search, Direct Lead, and imported legacy candidate path must pass the same deterministic Page Qualification before faculty extraction. Fast-track may prioritize validation and skip broader exploration only after acceptance; it never grants trust, old HIGH/100 values are not authority, and LLMs do not decide qualification. This deliberately trades some speed, legacy convenience, and edge recall for college-isolation safety, reproducibility, and auditability.

## Considered Options

- URL fast-track as automatic admission was rejected because URL tokens do not prove page purpose or College Attribution.
- Numeric score thresholds were rejected as the canonical decision because their additive values are not calibrated probabilities and lose hard constraints.
- LLM adjudication was rejected because qualification must remain deterministic, reproducible, and fixture-testable.
