# ADR 0004：临床师资的来源与归属证据

状态：2026-10-10 按用户重新确认的官网全师资范围修订。业务目标见 [CONSTITUTION.md](../../CONSTITUTION.md)；实现是否完整符合该目标仍需核对。

目标学院的官方师资名录可以证明名单与学院的师资关系，包含官网明确列出的兼职、外聘等人员，不要求额外证明专任编制。

合作医院的医生目录不能整体当作目标学院教师名单。医院个人页若明确写出目标大学／学院的当前教学科研任职，可提供归属证据；医生头衔、合作关系、校友经历或旧新闻本身不能替代当前归属。兼职身份本身不是排除理由，具体学校／学院关系仍须核实。

保留未确认的来源及任职证据进入核验，记录排除的实际理由。现有 server/harvest_eligibility.py 对医院候选的判断应纳入真实临床学院样本审查，不能以本 ADR 已更新推定代码已对齐。
