# 图片正文复核与跨站验收实施计划

> 用户已批准“低置信原图复核 → 断点完成 45 图核对 → 第二个可访问扫描 PDF 样本”的顺序。本计划只处理图片正文；不改变模型只侦察结构、教师字段由本地算法提取的边界。

**目标：** 人能在本地页面核对 OCR 低置信行，决定只对完全相同的原件和 OCR 行生效；真实浏览器断点补齐图片证据，并用另一所官网扫描 PDF 验证形态覆盖。

**架构：** `server/image_bio_review.py` 从审计、原图和本地 OCR 证据生成仅含待核行的复核页面与本地决定文件。决定以原件 SHA-256、页码、行序号和 OCR 原文摘要绑定；批量采集复跑时重新访问并核验原件，匹配才应用人工确认或更正，原始 OCR 证据永不覆盖。不匹配时继续保持未解决状态。

**技术：** Python、Pillow、RapidOCR、Playwright、pytest；复核服务仅监听 `127.0.0.1`。

## 完成标准

复核页面可在本机打开并保存决定；篡改证据会让决定失效；同一原件的断点复跑避免重复 OCR；45 图页面在本轮获得完整覆盖审计或明确列出仍待人工复核的唯一阻塞；第二所官网样本有真实浏览器与 PDF 对象级证据。正式大学 Excel 仍需专任教师范围核对和全部学院完成，不由本次样本试跑发布。
