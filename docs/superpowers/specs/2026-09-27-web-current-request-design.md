# 当前请求与历史工单界面

用户要求前端适配当前服务器自动采集，并指出右侧持续展示绍兴文理学院十一学院待复核。数据库保存两批各十一学院历史完成记录，页面会恢复旧 localStorage 批次或全站 latest 批次，混淆当前与历史。

本次按已有持续改进授权执行：默认右侧为空；仅恢复本浏览器仍在运行或排队的请求。结束的旧请求通过历史入口显式查看，提供返回新任务按钮。单院和批次采用统一持久化指针，切换任务清理旧结果；不删除、重排或改写历史工单。失败网络恢复保留指针，404 清理失效指针。

前端说明改为服务器常驻接单、dsh/DeepSeek 结构侦察、真实浏览器和确定性完整正文提取、大学审计交付。后台在线来自 SQLite 实例心跳，过期或未连通显示离线/未知；不以在线推断 API 余额或采集成功。历史列表只返回请求元数据，实际阻断和下载门禁沿用已有接口。

当前 dsh 侦察必须从已给定的官方 URL 开始。前端和后端均要求单院入口 URL，批量每行必须有学校、学院和入口三项；先验证整批再入队，避免只填名称却让 worker 必然失败。后续若加入可信的官网自动发现，可再改变此契约。

验收：预置历史批次或无缓存都不能自动占据右侧；运行中单院/批次可恢复，历史显式打开可见十一学院并保持下载阻断，新请求不会被旧异步响应覆盖；心跳在线/过期/关闭可区分；生产数据库任务数量保持。真实浏览器验证不点击采集提交、不请求 DeepSeek。
