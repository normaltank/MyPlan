# 随机新学院的适配性验证

用户指出旧验证集中于少量院校，授权自行随机找学院测试并继续完善。本轮先冻结样本再观察结果，禁止用成功网站替换不可访问或失败的样本。

## 抽样与边界

优先使用教育部最新普通高校名单，限定本科层次以匹配现有产品业务；完整列出候选框、来源摘要、随机种子、旧样本排除规则。抽取六所学校，每校从官方院系导航中随机选择一个教学学院，并保存导航候选与随机选择记录。若来源获取失败，记录该失败及替代抽样框的局限，不能声称全国随机覆盖。

每学院独立真实浏览器子智能体完成导航发现、结构选择器与分页核验。全部立即尝试派发；宿主容量拒绝须记录原始错误并补派。人工核实计划的确定性采集与服务器 Harness 自主侦察分别报告，不将前者当作后者指令遵循证据。不向生产队列写入测试工单或混入交付资产。

## 验收

每个抽中样本都进入结果分母，未派发、打不开、无法形成计划、阻断与通过分别统计。网页、截图、浏览器导航证据、计划、完整记录及审计保存在本地独立目录；主控只接收紧凑结果，不转写教师字段。

至少保留独立于采集器的名录结构计数/链接摘要和个人页完整正文核验，不能只用“自己提取的总数等于自己导出的总数”判断正确。发现错误先保存真实快照并加失败回归，再修结构算法；禁止增加目标域名特例、关键词黑名单或降低门禁。

部分新样本保留作修复后的验证，不根据结果重新选样。本轮结果只代表这一组样本，不推导全国成功率。修复后跑相关回归、独立复核及全量测试；必要时在空闲队列更新服务并核验前端。
