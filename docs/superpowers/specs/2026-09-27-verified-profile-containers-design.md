# 经核实的个人页正文范围

随机新站的独立核验在宁夏医科大学、传媒大学及四川工商学院发现：旧算法保留了全部履历，但最大的阅读容器还包含栏目与发布信息。继续添加关键词或站点类名黑名单不能解决通用边界问题。

## 接口与证据

每个名录分支可声明 `profile_content_selector`，只有实际个人页的浏览器结构核验通过才接受。若正文没有独立包裹节点，可额外声明 `profile_content_start_selector`：它必须是唯一容器的唯一直接子边界，复制其后所有节点直到容器结束，包含直接文本。这是实际 DOM 范围选择，不按关键词或字数裁剪。

浏览器新增范围核验工具，只返回 URL、CSS、结构计数及摘要，不返回姓名、职称、邮箱或简介。服务器在名录工具实际返回的最多两个不同详情样例上要求相同选择器的成功证明。少于两个详情时检查实际可用的全部样例；无个人主页名录不要求正文选择器。模型只决策结构，全部字段仍由确定性代码复制和提取。

采集期间每个详情重新检查范围。没有、多个、隐藏或非法容器以及非直接子边界均阻断；同一个人页从不同分支获得不同范围时保留观察并复核。保存原始网页，范围副本仅用于解析；审计保存两 CSS、原始与所选 HTML 摘要。正文全文门禁不能拿未经同一范围限定的整页与已限定正文比较后误报丢失。

旧手工计划兼容；生产侦察实际浏览器返回详情样例时须提供证据。永久复用仍重验个人页范围；新契约不伪造升级历史方案。真实保存页面回归、局部测试、独立复核及随机目标实时重测分别记录。

稳定性比较两次完整保留正文的 HTML 摘要及正文、祖先的计算样式事实，正文范围或祖先的运行中动画拒绝；正文外无关轮播不改变正文证明。请求活动和失败检查保持。最终原始 HTML 由仅本地 Python 的捕获通道与证明摘要绑定，侦察结果仍只返回结构事实。失败证明进入审计，不丢失隐藏/不稳定/网络失败原因。

## 页面环境隔离

深圳职大实际官网覆盖原生 Map，影响 Playwright 主世界注入和返回值序列化。通用修复将侦察脚本和结构求值放入 CDP 独立工具世界，保留网页自身 Map。原生 count/click 使用 Playwright utility 世界；官方页数据和脚本不改写，不绕过校内访问限制。
