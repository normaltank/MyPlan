# 明确空态名录的安全确认

用户授权持续完善采集工作流。只支持普通单页名录的明确可见空态，不将零卡片、空 DOM、加载失败或图片名录自动视为零人。

## 证据契约

模型只提交成对 CSS 字段 `empty_state_selector` 和 `roster_container_selector`，保留 `card_selector` 和 `single_page:true`。侦察工具和独立采集浏览器都重新证明：容器/空态唯一可见、空态位于容器内部、全部卡片为零、除空态和布局祖先外无其它名录内容；容器内隐藏内容、图片/背景图/iframe/媒体、busy 与分页候选阻断。网络和 DOM 需稳定；失败或超时不能确认空。没有空态提示的全空页面保持复核。

证据只包含 URL、selector、计数/布尔值、时间、HTML 摘要；不含空态文字或教师字段。绑定当前 HTML 后，reconciliation 独立检查无候选、卡片零，才豁免该页的两个缺人数问题。任何候选保留并报冲突，不得丢人。coverage 仅在绑定证据通过时认可空分支终页，全部其它分支和大学交付门禁保持。

空分支不能直接恢复已完成旧快照，须本轮浏览器重验；原生 Chrome 的 HTML fallback 不能提供空态证据。结构库复用传入新字段并重新验证。更新侦察指令将改变契约，旧版本仍保留但不能冒充新契约已验证方案。

本轮按本地真实浏览器回放验收，不发起模型 API，不重排历史失败工单。实际法学系如果没有明确空态，则仍待复核，不报告历史工单解决。
