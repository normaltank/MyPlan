# 分页途中续采

## 授权与范围

按用户持续完善项目的授权，补齐已说明的分页断点缺口。相同学院工单、相同完整计划、24 小时内才恢复；永久结构库和模型用途保持。

## 选择与证据

无条件从保存的下一页 URL 开始会跳过控件状态变化，完整重走安全但浪费。采用最后成功页重验证：快照与分支进度每成功页落盘，恢复时重新打开最后成功页，比较名录卡片及下一页 DOM 结构，匹配后点击计划指定控件继续。

只恢复同官方主机、不同 URL 可还原的普通分页，无 initial_click_selector；同 URL AJAX、过期/损坏/不连续快照、前沿页面变化或不能还原都保守从入口重走。保留原快照时间，不把验证刷新当作重新采集。

## 完成条件

原先保存页与本次新页一起参与候选/卡片对账和覆盖审核；必须取得终页证据，未到终页仍不得交付。续采不增加最大页数预算，不把页数上限当终页，不调用模型。取消时已成功页及游标持久，下一轮继续；游标只引用本计划分支的连续快照。

## 验收

真实 Playwright 回放三页名录：第一次到第三页前中断，第二次访问第二页和第三页，完整保留第一页记录；页面改变/损坏/AJAX回到入口；原保存时间不变、上限仍阻断、终页仍必须核验。覆盖与教师正文预期不削减。
