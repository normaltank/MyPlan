所有待采集学院仍立即独立派发，不加项目级并发上限。模型仍只用于结构侦察，产出计划没有教师字段；确定性内核提取完整简介，不新增模型调用、关键词黑名单或正文截断。

## 修复的实际缺陷

- 跨页相似履历被识别为模板，正文容器缩至姓名，邮箱和履历消失。固定验收先失败；修复后完整段落保持。独立共有页脚仍隔离，旧邮箱回归预期未改。
- 共享个人页的单人正文被与整页所有人的正文比较，造成错误阻断；现按个人容器处理。
- 访问失败的次生 `fetch_failed`、分支终页缺证据以及导航子页归属使纯访问问题触发模型重侦察；现按失败 URL 与父分支归属识别。
- 一个分支会话可借用另一分支的浏览器事件；现每阶段只使用自己的事件验证。
- 同学校/学院/入口的跨工单计划复制可误恢复；现校验工单 ID、完整计划和时间，恢复不会延长有效期。
- 传入旧 HarvestState 可绕过新计划的就绪条件；run_plan 显式校验完整计划摘要。
- 失败模型阶段消费丢失；现 `recon-attempts.json` 与失败工单 stats 的证据路径/摘要保留审计。
- MCP 阶段和证据会话现通过子进程配置显式传递，避免依赖不同宿主的环境变量继承行为。

## 边界

覆盖账本范围是已核实名录分支，人数守恒不能证明整个官网没有漏发现入口。结构缓存只支持已实现的普通名录形式，动态 Tab、重定向根入口、导航树等仍保守重新侦察。普通 URL 分页现在可验证最后成功页并续采；同 URL AJAX、变动、过期或损坏的前沿仍从入口重走，完整计划变化时旧状态隔离。字段来源目前到候选/个人页与快照，尚未逐字段保存 DOM 路径。

## URL 分页恢复与严格空态证明（追加实施）

逐页保存连续快照引用及分支游标，恢复时重新访问最后成功的 URL，检查卡片及下一控件的两次 DOM 签名、实际 URL、导航前安装的请求追踪、未完成请求与失败请求。通过后保留原捕获时间、原页数预算，继续下一页；不满足则回到入口，不能重置最大页数或凭缓存补终页证据。真实取消、页面失败、延迟 DOM/AJAX、损坏与非连续引用、同 URL 翻页及上限均有回归。

明确空态仅支持普通单页名录。模型计划只新增空态提示和名录容器的 CSS 选择器；真实侦察工具证明及确定性采集浏览器分别核验，不接受模型自报零人数。证据绑定 URL、三个选择器及 HTML 摘要；唯一可见提示须在唯一可见容器内，没有教师卡片、其它内容、隐藏内容、媒体、忙碌状态或分页，网络和 DOM 均须稳定。空态分支不恢复旧完整快照，原生 HTML 降级也不能确认空态。全学院零人进入 `zero_person_delivery_requires_review`，不导出、不反复调用结构模型。

本地合成 HTML 的真实 Playwright 端到端回放：第一次在第三页中断，保存两条观察；续采仅访问第二页、第三页和第三位教师主页，三条完整记录、完整覆盖、原时间保留。一个严格确认的空态分支与普通三人分支可以一起完成覆盖；无空态提示的空白页面仍阻断。证据：[持久回放结果](../../scratch/pagination-and-empty-replay/result.json)。这些样本不是本轮官网采集，模型请求、Token 和生产新工单均为 0。
