# 外国语学院反复人工复核：背景照片与姓名空白比较

目标：山东政法学院外国语学院；工单 `7d397b9a7eec4309a7648cace299e529`，批次 `bc74391e`。以 `5409f53` 为本次独立分支基线。

## 两个已复现的问题

最新审计保存 50 条中间记录，未解决项为 8 个 `image_bio_owner_unresolved` 和 1 个 `profile_identity_not_found`。已保存的 27 行人工 OCR 决定全部命中原件和原始 OCR 行，最新媒体证据也记录每张图有 3～4 行人工复核。不是审核没有保存。

逐一查看八张原件，都是人物站在学院宣传板前的照片。图中只有学校/学院背景标牌，没有本人履历、联系方式或学术内容。旧程序把浅色背景判作可能的文字资料，再要求 OCR 标题包含本人姓名；即使背景校名全部纠对，也不能匹配姓名。旧重试门禁只验证行决定是否已保存，未检查纠字是否真的解决图文归属，于是再次入队后返回相同问题。

另一条个人页错误：名录里的外籍教师姓名含两个空格，网页标题有同一姓名，但身份检查只去掉网页文本空格、没有同步处理姓名。旧比较失败，对称处理空白后匹配成功。该问题与八张照片无关。

本地审计文件会在同一个 attempt 上更新，因此本次证据能证明最后一次重跑仍在重复相同归属问题，不能从这些文件独立重建用户此前每次操作的完整时间线。

## 修复行为

- 沿用原图类型复核，在 `media_kind_review.STATUSES` 中加入图片简介归属/低置信 OCR 的既有状态，仍由 `review_registry` 统一接线。展示整张原图，复核人可确认“非简历照片，仅照片或背景文字”；履历、联系方式、学术内容、扫描简历或无法判断时继续文字复核。不按大学/学院名称做关键词过滤。
- 照片决定继续绑定个人页 URL、媒体 URL、原件 SHA256、操作者和时间。重新取得同一原件时跳过其背景文字作为简介的数据用途，原图和原始 OCR 不删除；换图、换 URL 或跨个人页均不能借用旧决定。
- 有效照片决定能同时完成该图类型及 OCR 归属复核，无需再纠背景字。真实简介仍可通过纠正 OCR 标题、唯一匹配已保留候选人而完成，不强迫声明为照片。
- 原图未确认非简历且 OCR 纠正后仍不能唯一匹配本人时，重试门禁保持未完成，避免只因保存过文字就再次入队空转。
- 身份比较两边一致去掉空白，仅改变比较键，名录姓名与正文原文不改；其他人的个人页仍被拦住。

## 准确性与运行边界

可排除的是经整图核实的非简历照片用途，不是“包含校名”的任意文字。学校名称同样可能出现在教育经历里；仅凭关键词排除会漏掉真实简历。混合图文卡片、包含本人履历/联系方式/学术信息的照片式设计和不确定图片都应继续处理。决定保留原件、身份绑定与时间，便于核查。

本次未代替用户给八张生产图片作审核决定，未重启服务、未重新入队或宣称学院交付完成。加载修复后，用户可在整图类型复核中确认照片用途，再按同工单重试流程验证全部目标范围。
