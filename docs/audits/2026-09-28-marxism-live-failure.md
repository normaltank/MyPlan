## 工单与调用链

- 本地用户未手动打开 dsh 窗口。常驻 `server.agent_worker` 在接单后自动启动项目内的 DeepSeek Harness；Harness 使用 DeepSeek API 和 Playwright 浏览器进行结构侦察。数据字段由确定性采集模块提取。
- 原失败原因：侦察计划的详情正文选择器核验报 `profile_content_not_verified`；worker 依门禁停止，未发布不完整 Excel。

## 根因与修复

1. 官网详情页正文容器外的一张图片返回 HTTP 404。旧核验把全页任意失败请求都视为正文未稳定，导致正确的 `#vsb_content` 选择器被拒绝。现在仅忽略经 DOM 证明位于正文容器外的 404/410 图片；其他失败仍阻断。
2. Playwright 的 `networkidle` 预等待超时会使核验提前退出，丢失已加载的正文证据。现在超时后继续运行独立的请求追踪、DOM 双快照、可见性和动画检查；这些检查仍决定是否通过。
3. 名录中部分链接文字在姓名末尾带装饰性的 Unicode 符号。原姓名评分因此把一个 12 条的结构相同分组整体排除。现在按 Unicode 符号类别去除姓名两端装饰符号，无需针对学校维护符号或姓名黑名单。
4. 请求追踪新增失败资源元数据后，一个模拟请求测试缺少 URL 属性。兼容缺省属性后，相关测试恢复通过。
