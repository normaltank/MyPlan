# 六所新学院随机验证与通用适配修复

## 抽样与证据边界

本轮回应“反复使用相同学院页面会掩盖适配缺陷”的问题。先基于教育部 2026 年本科名单排除 27 所历史样本，冻结 6 个不同省级地区的新学校；每校从真实官方教学单位导航再随机选择一个学院。种子、原始名单摘要、候选和复现脚本见 [抽样方法](2026-09-27-random-sampling-method.md)。所有失败学校都保留，没有换成好采集的学校。

采用一学院一专属子智能体。宿主并发容量拒绝和余额中断均记录在 [派发记录](../../scratch/random-college-validation/dispatch-log.json)，原样本续接完成。本轮没有生产工单、没有 DeepSeek API 请求；学院结构由 Codex 学院子智能体通过真实浏览器核实，教师字段由确定性算法提取。它验证采集内核与工具，不等于 DeepSeek Harness 已自主完成这六校的指令遵循验收；Token 为零指后端 DeepSeek 消费，不包含本次 Codex 开发会话。

## 通用修复

### 实际核实的完整正文范围

计划可以声明已核实的 `profile_content_selector`；正文没有独立包装节点时，可成对声明 `profile_content_start_selector`，必须是唯一正文根的唯一直接子节点。正文范围由 CSS/DOM 结构决定，不用标题关键词黑名单或长度截断，不生成简介摘要。

侦察对最多两个实际、不同的个人页样例逐一验证，样例从全部卡片先去重再取两个，并支持卡片本身就是链接。没有个人页的合法名单不凭空补范围。确定性批量采集对每份详情重复真实浏览器验证，不把两个样例外推成全站证明。

原始 HTML 始终完整保存。计算样式检查正文根、祖先和保留的后代，隐藏内容、空范围、多匹配、范围冲突、加载失败与缺少证明均保留观察并阻断。有范围声明的任务快照即使未过期，也须本轮重新访问；同一 HTML 保持原捕获时间，变化用真实新捕获，当前验证时间另记。原生浏览器 HTML 兜底不能绕过范围证明。

### 官网脚本与工具隔离

深圳主页的旧脚本自定义 `Map` 改变了页面全局环境，导致 Playwright 的主世界序列化异常及链接值失真。工具改用 Chromium 公共 CDP 的隔离世界读取同一真实 DOM；官网脚本保持自身行为。worker、侦察工具、缓存验证、批量和图片工具采用统一上下文入口。真实官网及本地回归同时检验链接一致与旧脚本继续运行。

### 正文外动画与真实失败分别审计

最终实时测试发现中传正文外轮播的 `opacity` 动画持续改变整页 HTML；19 份抽检正文范围摘要均相同、无网络失败，可见性事实也一致，整页稳定检查却产生误阻断。差异原 HTML、DOM 路径与计算样式证据见 [动画诊断](../../scratch/random-college-validation/cuc/final/scope-diagnostic/result.json)。

四川工商独立诊断则确认部分图片返回 404，另有瞬时网络失败。实际资源问题不能用动画修复绕过，负验证也应保留紧凑结构证据。所有修复前失败、首次修后和最终版本结果分别保存，不覆盖不利结果。

修复后比较两次完整保留正文 HTML 摘要、正文/祖先计算可见性与样式事实；范围和祖先的运行中可见性动画拒绝。完整原 HTML 通过仅本地 Python 捕获通道精确绑定证明；侦察工具保存同一 HTML，返回结果不包含原文。负证明保留 `selected_dom_stable`、`visibility_stable`、请求计数及错误类型。中传终测 23/23 通过；四川工商单轮终测仍有 13 份失败，见 [负证明汇总](../../scratch/random-college-validation/stbu/final-v2-failure-summary.json)，没有反复重跑选择有利结果。

## 验证和部署记录

固定解释器 `.runtime/worker-venv/Scripts/python.exe`，隔离数据库 `scratch/verification/tasks.db`。最终全量 `pytest tests -q`：**365 passed、1 skipped，164.65 秒**。唯一跳过仍来自缺少历史源码归档。首次全量的两个旧 worker 测试仍断言原始上下文身份；改为验证隔离上下文包装及其原上下文身份，并保留任务断点、租约和关闭断言，相关 15 个测试通过。

独立只读复核无剩余 P1/P2：相关 57 通过、最新稳定性 7 通过，并独立运行外部轮播、祖先动画、正文变更、样式失败四个真实浏览器场景，检查原 HTML 摘要绑定和工具结果无正文。实现者的相关范围/断点/分页/缓存/兜底回归 82 通过。新站现象均先保留失败证据，再通过通用修复与真实重测确认，未增加任何学院特例。

汇总结果 **6 校已测试，1 校通过独立验收、5 校保留阻断，0 未测试**。最初采集报告虽有 1 校 ready，但正文噪点使独立验收为 0；修复后宁夏成为独立通过。分阶段摘要 [baseline](../../scratch/random-college-validation/summary-baseline.json)、[after](../../scratch/random-college-validation/summary-after.json)、[final](../../scratch/random-college-validation/summary-final.json) 与全部旧结果保留，最终版本来源显式列出。不是全国成功率。

## 未完成的产品能力

这是强调地区差异的两阶段随机样本，全国学校入样概率不相同，6 校不足以证明全国适配率。参与修复的样本是回归样本，不能改称未经影响的留出成绩。三个未参与正文修复推导的样本仍受入口或公开名录限制，本轮没有成功的独立留出采集成绩。

校内访问、没有公开完整名单、仅空 DOM 分支、图片/PDF 正文、同名身份裁决仍需对应证据与工作方案。新增结构证明会增加少量浏览器访问和侦察结构信息；教师正文依然不生成 Token，永久方案复用仍须新证据，不能宣称所有新任务零 Token 或六校自主履约全部成功。
