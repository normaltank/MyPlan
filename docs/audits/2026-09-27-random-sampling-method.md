# 新学院随机抽样方法

## 目的与历史边界

用户指出此前反复复用相同学院页面，可能掩盖适配问题。项目既有验收确实主要依赖合成结构、湖南中医药大学信息科学与工程学院保存页，以及湖南师范大学和山东中医药大学的少数实时入口。既有通过结果不能证明多校随机适配，详见 [原验收范围](2026-09-26-harvest-acceptance.md) 和 [实时验证记录](2026-09-27-verifiable-harvest.md)。

本轮先冻结抽样框与样本，再由每校专属学院智能体核查导航、随机选一个教学单位，使用真实浏览器测试。失败学校和学院仍属于样本，不按访问成功、师资人数、网页结构或导出结果替换。

## 官方来源

教育部于 2026-06-18 发布截至 2026-06-17 的 [全国高等学校名单](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/A03/202606/t20260618_1441074.html)，普通高校包括 1412 所本科学校。抽样采用其 [全国普通高等学校名单 XLS 附件](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/202606/W020260618416094865984.xls)。精确附件链接同时存在于 [天津财经大学官方转载](https://fzzl.tjufe.edu.cn/info/1035/1713.htm)。

教育部正文直接请求最初返回 403，网页检索工具打开正文超时；使用附件精确 URL 加普通浏览器 User-Agent 后成功取得原始 XLS，未采用第三方整理名单。附件大小 464896 字节，SHA-256：`29c40f083b639888e429cf40b68f9a75782d1ce81131c99aabca65b65b36eaea`。解析得到 2952 所普通高校中 1412 所本科，与官方摘要一致。原始附件保存在 [list.xls](../../scratch/random-college-validation/sampling/list.xls)。

只下载官方名单元数据，没有用 HTTP 抓取教师页面；教师网页测试必须使用真实浏览器。名单解析工具 xlrd 2.0.2 仅放在 scratch 的 vendor 目录，未修改生产固定环境和依赖锁。

## 冻结方法

- 冻结时间：2026-09-27 04:35:35 UTC（12:35:35 UTC+8），在查看所选学校师资测试结果之前。
- 随机种子：`2026-09-27-new-college-cross-site-v1`。
- 范围：教育部原始附件办学层次为“本科”的学校，包含普通本科与职业本科、公办与民办；本轮不覆盖专科和港澳台学校。
- 排除：从项目输出文件的学校名称与交接记录中提取历史样本，与当前名单精确匹配，排除 27 校，剩余 1385 校。排除是减少重复样本，不是因网站难访问。明细见 [excluded.json](../../scratch/random-college-validation/sampling/excluded.json)。
- 方法：先将剩余省份按 Unicode 排序，使用 Python `random.Random(seed).sample(provinces, 6)` 抽取 6 个不同省级地区；每个地区学校按教育部学校标识码排序，依次使用同一随机数实例的 `choice` 抽取 1 校。
- 这是强调地理覆盖的两阶段随机样本，各学校的全国入样概率并不相同；不能称为全国学校等概率随机抽样，也不能用 6 校计算可信的全国适配率。
- 不重抽：网站打不开、无公开师资、图片名录、学院名单无法证实或覆盖失败都保留，记录实际结果。

完整原始框、冻结 JSON 与复现脚本在 [sampling](../../scratch/random-college-validation/sampling/)；执行 [reproduce_sampling.py](../../scratch/random-college-validation/sampling/reproduce_sampling.py) 验证原始附件摘要、人数与名单一致，脚本不会覆盖冻结文件。

## 学院选择与结果报告约束

每校专属智能体先用真实浏览器打开上述官方入口，核实官方教学单位导航；保存候选学院名称、URL、原页面路径与捕获时间。候选学院应来自官方当前教学单位列表，避免将职能部门、实验平台或招生专业名称冒充学院；同名不同链接先记录导航歧义。

在查看师资页面结果前，冻结当前可证实的学院候选列表，按名称及 URL 排序，以 `seed + ":" + 学校标识码` 为种子随机选择 1 项，同时保存选择规则。学院没有独立 URL 或官网无法访问时记录该学校的选择失败，不换学校；选中学院没有公开名录时记录覆盖受限，不换学院。教学单位候选排除依据也需保存，不能事后排除没有数据的单位。

本文件只冻结学校层级抽样，不预先宣称学院导航完整。学院实际冻结与访问、列表覆盖、详情完整性、身份问题及模型消费由各学校测试证据另行保存。本轮报告至少逐校列出：是否真实访问、选中学院、名录形态、实际分支与分页、记录观察数、未解决项、是否可交付、模型请求/Token 和本地证据路径。

若修复从样本发现的通用缺陷，保留修复前失败与修复后重测，结果不能改称未经训练影响的独立留出成绩；至少保留未参与修复推导的样本作为后续验证。随机取 6 校仍不等同于完整产品适配性证明。
