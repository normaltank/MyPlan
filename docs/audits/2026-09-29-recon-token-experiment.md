# 侦察 Token 实验（2026-09-29）

目的：在不降低采集效果与精度的前提下减少侦察阶段的模型请求与 Token。方法：同一批学院、同一天、同一环境，用 worker 的生产路径（侦察 → 确定性采集 → 审计，含补缺轮次）分别跑改动前后的代码，比较请求数、Token 与采集结果。

## 环境与口径

- 云端 Linux，Python 3.12，Playwright 1.47 + Chromium headless shell，DeepSeek `deepseek-flash`，reasoning effort `high`（F 组为 `off`）。
- 学院：湖南中医药大学信息科学与工程学院、山东中医药大学卫生管理学院、绍兴文理学院教育与心理学院、湖南师范大学国际汉语文化学院（均曾在本机交付）。宁夏、内蒙古站点从云端无法访问，未纳入。
- 云端访问部分学校图片返回 403（`image_bio_asset_failed`），这是环境差异，两组同样受影响；它会触发额外补缺轮次，使整单 Token 偏高，本机运行不会出现。
- 费用按官方价目（deepseek-flash 峰时，USD/百万 Token）：缓存命中 0.006、未命中 0.3、输出 1.2。

## 开销从哪里来（历史 71 个会话 + 本次基线）

- 显示的 Token 约九成是缓存命中：每次请求都重新发送整段对话。请求越多，前面的上下文被重读得越多。
- 费用约八成来自输出 Token（思考过程）。按上面价目，历史上"314 万 Token"那次约 0.3 美元。
- 模型最常做的是自己写 JS 读取标题和正文（573 次，占工具调用 38%）：发现阶段基本是"打开一页、再读一次正文"，每页两次请求；每次打开页面还会把全站菜单链接完整重发。
- 分支阶段请求数高的会话，全部卡在个人页正文验证返回 `confirmed:false`：原因是页面上与内容无关的状况（正文里 Word 粘贴的 `<style style="display:none">`、编辑器留下的隐藏占位 `invisible`、主题 CSS/JS 被服务器 404），模型无法通过换选择器解决，只能反复尝试直到 25 次上限。
- 另一处：模型核验了名录第 2 页的两个个人页，门禁却只认第 1 页的样例，导致整轮计划被拒、重来。

## 改动

1. `browser_navigate` 同时返回页面摘要（标题、标题行、常见正文容器计数、本会话尚未出现过的页面文字）；已返回过的链接与重复的菜单/页脚文字不再重发。
2. `browser_navigation` 支持 `query` 按关键词筛链接；发现阶段新增 `browser_survey`，一次查看最多 8 个候选页。
3. 个人页正文验证：`<style>` 等不渲染的元素不算隐藏内容；只有几个拉丁字母、无中文/数字/邮箱的隐藏占位不算隐藏内容并从采集副本中去掉（任何可能是姓名、数字、邮箱或中文的隐藏文字仍然阻断）；字体、媒体失败，以及服务器明确 404/410 的样式表不阻断；404/410 的脚本只在正文与服务器原始 HTML 一致（服务端渲染）时不阻断；中断、5xx 等可能是临时的失败，以及正文内图片失败仍然阻断。同一请求"先 404、再被中止"只计一次失败。未通过时返回 `reason` 与阻断请求类型。
4. 正文样例门禁：名录入口页及其已验证的下一页上，任意两个不同个人页通过验证即可；未通过时把可选样例 URL 回传给补缺反馈。

- 改动前 4 所中 3 所在分支阶段触顶失败；改动后其中 2 所完成侦察并采到人员，另 1 所卡在下文的空名录问题上。
- 湖南中医药大学、绍兴文理学院两组的采集结果（人数、有邮箱人数）在改动前后、思考开关之间完全一致。
- 关闭思考后输出 Token 约减半、费用降约二成，但请求数略增；样本只有两所学院，暂不改默认值。
- 整单费用都在几美分量级；"Token 多"主要来自缓存重读，按次数计费的影响有限。

## 仍待处理

- 空的系所名录页：博达（VSB）列表组件显示"共0条"加分页按钮，不满足现行严格空名录证明（需明确空态提示且无分页控件），模型会反复尝试直到上限。需要决定此类页面的证明规则。
- 同一教师出现在多个无主页名录时的"同名不同主页"阻断（国际汉语文化学院 16 项）。
- 单会话请求上限（发现 40、分支 25）在改动后的正常会话中远未触及（发现 6–15、分支 8–18），保留为失控保护。
