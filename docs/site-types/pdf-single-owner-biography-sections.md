# 单人 PDF 简介跨页延续

状态：observed，非学院专用适配器。

已核实个人正文包含原生 PDF，页面只有唯一 owner，PDF 首页有该 owner 的人员标题／身份字段／介绍段；仅作者串中同名不够。后续页可以从论文作者或合作者文本中断续。页面位置和姓名提及次数不作为多人文档证明，完整正文保留。

实现：`image_biography.audit_profile_media` 调用 `pdf_biography_owner.inspect_owner_scope`，读取全部原件页的人员标题／身份字段及版式线索。存在其他人员章节、未知姓名章节或不可读取部分时阻挡，保存页／bbox／标题 SHA；不猜测把 PDF 的部分段落分给不同人。

固定原件证据：12 份 2–5 页 PDF，唯一 owner、来源 SHA 已核对，全文读取逐字保留。样本资源／摘要在开发目录 `.planning/review/civil-pdf-owner/`，不在类型模板中携带教师字段。

失败边界：多人来源、首部不能证明 owner、页证据不全、未读光栅、OCR 位置或文字不确定、孤立姓名作者行和陌生人员标题语法。未知形态不据本类型自动宣称完整；本观察不证明邮箱归属、学院范围或实网泛化。
