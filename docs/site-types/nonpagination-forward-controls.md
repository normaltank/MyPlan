# 已观察的非分页控件重查

状态：observed。来源为资源学院本轮保存页面及浏览器工具轨迹：模型把独立图片轮播箭头、当前页导航填为next_selector，控件持续存在，后续省略selector或重开页面仍被历史forward记录阻断。136是该页卡片数，不证明学院人数或完整性。

当前候选和已记忆控件使用同一非分页证据入口 `server/nonpagination_controls.py`；轮播直接复用采集侧既有banner规则，要求脚本箭头、媒体组件结构及与名录不相交，不新增站点／类名白名单。当前页导航必须是独立导航、带当前链接的栏目菜单或纯链接面包屑，同时绑定当前URI；仅同URL不足以解除分页疑点。正文／名录内链接、article/main内容、pager/next角色、显式动作属性、混合未证匹配继续待核。

证明绑定当前来源SHA、URL、名录selector、控件selector及每个匹配的原件摘要。记忆不被清空，之后DOM或角色变化要重新证明；非分页不是末页，不伪造terminal。工具和提交消费者使用共享validator。真正前进按钮即使省略selector仍须缺失、禁用或已有当前末页证明；位置位移保护见 [分页控件位移](pagination-control-position-shift.md)。

回归包括图片轮播、当前栏目导航、正文链接、实际AJAX加卡、轮播近名但承载名录、混合selector及证明来源变化。保存页和本地浏览器回放不等于当前实网或全院验收。
