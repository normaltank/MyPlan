# 页码窗口变化导致前进控件位移

观察状态：observed，非学院专用适配器。

同一名录组件的页码窗口随当前页变化扩展，前进控件的兄弟序号变化，但DOM作用域及控制角色保持。依赖序号的CSS会停止命中，不能据此证明末页。

实现入口：`server/pagination_identity.py`，由 `browser_batch_tool._capture_branch` 调用。以真实名录与控件的共同DOM作用域、祖先结构路径和角色摘要检测位移；发现差异交回结构核验，不自动扩大或替换选择器。

样本证据：信息工程学院导师目录本轮结构捕获，旧计划4页、已核实稳定控件9页，页容量10、末页9个链接。结构计数不证明人员资格、身份或学院完整性。观察登记不得携带教师字段或伪装成模板批准。

不适用边界：动态改变标签含义或组件结构、未核实的跨组件跳转、单页组件证明。其它未知形态继续留待核验。
