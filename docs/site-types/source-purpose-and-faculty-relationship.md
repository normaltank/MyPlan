# 人员来源用途与师资关系

状态 observed；非学院适配器。大学官网、师资导航邻近位置、委员会成员身份及同名，均不单独证明本学院师资关系。

未进入活跃分支的来源用途／结构未决，采用独立的来源页面复核类型，不制造逐人师资决定。员工核对保存原件后，可判定该页不是师资名录、请求重新侦察（可补充官方入口）、保持未知或撤回；补充说明选填，未填写时记录该审核人的结构化选项，不代写事实解释。打不开只允许保留未知或请求重读；不得确认无师资。决定绑定工单、大学学院、URL、来源角色与见证选择器以及原件 SHA；页面或目标改变时不沿用排除决定。用途排除只处理该来源，不删除逐人关系问题，不修改字段与身份。重新侦察请求只允许重新入队，当前结构问题仍由下一轮原生验证解决，不能当成采集完成。

来源用途决定应用后保留改选／撤回入口。更改已应用决定时沿用现有来源复核失效机制，保留原记录、阻断原结果继续交付并重新核验；未知和撤回不能满足重试门禁。HTTP错误页即使保存了HTML原件，也不支持用途排除。

结构计划声明受控 source_role 与完整正文、实际标题/当前页导航、独立学院上下文的 CSS。browser_verify_source 使用现有唯一可见/稳定DOM/请求结束证明，并保存完整当前HTML和用途见证SHA。正向师资标题或明确当前页导航及学院上下文才支持faculty关系；仅写枚举、普通侧栏师资链接不能放行。组织/未知来源仍读取并保留全部原件与候选，作为source_qualification_missing；不按委员、兼职、外聘或校名黑名单删除。

实际固定证据：两委员会原件SHA对应15条被选范围观察；旧全局标志直接纳入，新共同证据保持待核。教授博士介绍原件5条正式来源关系正例仍可纳入，不能将这5条当完整全院范围。原名单范围中未被旧选择器选中的文字仍在完整原件，人员集合完整性另行核验。

失败边界：只有图片中的用途说明、无可读取主标题或学院上下文、陌生师资表述、动态来源改变、无法唯一定位或证明全文范围，均保持未知。该类型不声称全院泛化或实时验收。

实际历史正常布局：湖南中医药大学信息科学与工程学院的学校名称位于底部官网链接，学院logo位于页头。source_context_selector现可用逗号组合同一已访问页的多个机构品牌/页头/导航/页脚区域，逐区读取并保存组合SHA；不要求学校与学院名称位于同一独立子树。正文/教师履历提校名不属于机构branding。

组合中的每个区域仍须是机构品牌区域。实际委员会页的版权页脚足以绑定学校学院；额外加入只写“首页／学院概况／机构设置”的普通路径导航，会使整体上下文校验失败。工具通过 `non_institutional_context_count` 和 `source_context_issue` 报告原因，调整须依据本页实际结构，不能降低归属校验。相应最小回归见 `tests/test_source_context_diagnostics.py`。

明确的组织名单用途与成员是否为教师分别核验。当前来源处置契约允许有正向组织用途、目标归属和完整原件证明的来源记录为 `not_faculty_roster`，仅退出活跃名录；这不声称其中成员不是教师。人员资格仍须正式名录或本人任职证据。用途或归属确实未明的来源保留待核，不能因为没有命中师资词表而排除。

机构区域的 class／id 也按 camelCase／PascalCase 词边界识别既有品牌词；这只修正 DOM 类型线索，不接受任意前缀或特定站点的类名名单。正文 article、整页或正文重叠、学校学院归属及导航外链校验保持；品牌区域识别不能代替当前页面的师资用途证明。
