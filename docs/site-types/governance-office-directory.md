# 党建组织任职目录

状态：已观察。适用于大学学院官网独立“组织建设”页，正文明确列出党委书记、纪委书记或党支部等带标签的组织任职。该类型描述来源用途，不判定成员是否为教师。

采用现有 `organizational_membership`／`not_faculty_roster` 契约：当前页用途标题须绑定自身标题或当前导航，完整正文须同时有组织任职标签，学校学院独立品牌证明仍须通过。普通工作总结、仅政策介绍或相反的教师名录主标题不能凭该词退出名录。原件与处置证据保留，未知成员不能据此纳入或从其它已证师资名单删除。

对应实现为 `source_qualification.organizational_purpose`，回归在 `tests/test_governance_source_type.py`。实际观察来自法学院本轮组织建设页面；上述规则不使用院名、人员姓名或站点路径特例。完整性与成员任职证据仍须另核。
