# 可验证的教师采集运行流程

2026-09-29 更新。实现保留 FastAPI、SQLite、DeepSeek Harness、Playwright 和确定性字段提取；学院任务立即独立派发，无项目级并发上限。

## 运行与完成条件

1. 工单锁定大学与目标学院集合。每学院有独立租约、输出目录与 Harness 会话。
2. 同工单在 24 小时内可恢复完整计划和成功页面。计划摘要、工单 ID、入口、指令契约、文件摘要及捕获时间必须匹配；恢复不刷新原捕获时间。有正文范围声明的个人页仍须本轮浏览器重新访问验证，不能从 HTML 快照推断计算样式可见性。
3. 新工单先检查永久结构方案库 `plan-cache/plans.sqlite3`。版本不因年龄自动失效或删除，但每次须重新通过真实浏览器检查发现页面全部链接指纹、名录卡片和实际下一页。契约变化、内容损坏、页面变化或证据不足则重新侦察。旧 JSON 自动导入且原文件和时间保留，相同结构去重，历史版本和紧凑验证记录永久保留。当前仅复用无初始点击的普通名录分支；重定向根入口、导航树、Tab 等形态保守地重新侦察。
4. Harness 按入口发现和分支核实分阶段执行。默认使用当前 Python 环境的 SDK 可执行程序和项目独立 `.runtime/dsh-home`；补丁实际插入浏览器插件，关闭 workflow/jobs/ralph 等通用工具。模型调用前检查实际合成配置，插件缺失或无关工具仍启用时失败且不调用模型。入口发现提交实际承载名录的页面；浏览器返回的 `linkedSamples` 只是卡片链接，需判断目标是个人详情还是子名录。目录型分支须验证父链接及子名录选择器。结构失败在同工单内保存已核实分支和发现证据，下一轮只重侦察失败分支，反馈仅传对应阶段；连续同一问题且没有新增分支证明时停止。采集审计失败后的无故障分支先经本轮浏览器验证，再跳过其模型阶段。MCP 子进程的阶段和证据会话通过启动参数显式传递。
5. Playwright 捕获的每个成功个人页和名录页立即存入任务内 SQLite 与 HTML 文件，分支游标只引用连续、完整、未过期的快照。终页已证明的完整分支可恢复完成；普通不同 URL 分页可重开最后成功页，核对请求已完成、稳定窗口无网络活动、卡片和下一控件两次 DOM 签名相同后继续采集，原快照时间保持。页面改变、快照损坏/过期、同 URL AJAX、动态初始点击或跨主机等不能可靠还原时从入口重走。恢复不重置最大页数预算，也不省略终页证明。
6. 页面访问失败先在同计划下补缺最多两次，复用成功页面，不重新调用模型。资格、分页、身份和正文冲突继续阻断交付。个人页底层有有限访问重试，不能把重试次数解释为模型请求。
7. 确定性代码提取十列数据和完整正文。跨页共有正文不能被模板相似度直接删除；独立共有页脚继续隔离。共享个人页按各人的容器提取，不与整页全部人员正文做不适用的长度比较。
8. 全部目标学院完成且无未解决项后，生成大学双 Sheet 版本文件和 manifest。学院中间结果可以先同步；大学状态仍为 collecting 或 blocked 时没有本批完整大学下载。
9. 同名异主页是身份观察歧义，不能自动合并，也不能仅凭不同 URL/正文当成两人。采集导出前、队列收据和大学汇总都阻断这类观察，保留各份完整正文与来源。结构模型不能裁决身份，因此不重复侦察。下载先按文件自身 manifest 的原始工单集合审核，再检查当前交付范围；新任务完成不能使尚未替换的旧问题文件重新可下载。blocked 返回 409，原文件保留。单任务和批次前台均显示观察数与待核算人数，隐藏下载；批次待复核时停止轮询。
10. 明确可见空态的普通单页名录，可成对声明 `empty_state_selector` 与 `roster_container_selector`。侦察和独立采集都须证明唯一可见空态、零卡片、容器无其它内容/隐藏内容/媒体/分页、网络与 DOM 稳定，证据绑定本次 HTML 摘要。网络跟踪必须在导航前安装，单独的历史 networkidle 标志不能作为证明。空态分支计入覆盖并贡献零人；完全空 DOM 或无空态提示仍复核。旧完成快照与原生 HTML fallback 不能确认空态；全学院确认零人仍以 `zero_person_delivery_requires_review` 阻断交付，停止结构模型补缺。
11. 实际个人页正文用已核实的 `profile_content_selector` 隔离；没有独立正文包装时可附加唯一直接子节点 `profile_content_start_selector`，完整保留其后的节点。侦察核验最多两个不同实际详情样例，批量采集逐详情重复本轮浏览器检查。空、多匹配、范围冲突、隐藏根/祖先/后代、加载失败和缺少证明均阻断；HTML 兜底不能替代证明。稳定性比较完整保留范围和正文/祖先计算样式，正文外无关轮播不误触发；范围或祖先运行中动画阻断。CSS、原始及所选 HTML 摘要和真实验证时间进入字段来源审计，负证明保留失败计数；本地捕获与原 HTML 摘要绑定。当前浏览器工具使用 Chromium CDP 隔离世界，避免官网旧脚本覆写全局对象污染工具输出。

## 本地证据

| 文件/模块 | 说明 |
| --- | --- |
| `server/outputs/tasks/<task_id>/active-plan.json` | 工单绑定、完整计划与历史模型尝试，24 小时期限不因恢复延长 |
| 同目录 `page-state/<plan_digest>/pages.sqlite3` 与 `html/` | 成功页面、内容摘要、原始捕获时间；完整计划变化使用新分区 |
| 每次采集的 `*_coverage.json`、`*_audit.json`、`*_snapshots/` | 计划分支、实际页面状态、可见卡片、候选、资格、个人页、失败原因与原始 HTML |
| 同目录 `recon-attempts.json` | 成功/被拒绝/失败尝试已报告的模型消费；超时与不完整运行标明 `usage_unknown`，不能当成零消费 |
| `server/outputs/plan-cache/plans.sqlite3` | 永久结构版本与验证状态；仅结构计划、URL 与链接指纹，没有教师字段；旧 JSON 保留作为迁移来源 |
| `server/outputs/versions/<school_hash>/<version>/<大学>.xlsx` 与 `manifest.json` | 本批目标学院范围内的不可变大学版本；前台下载指向这个版本 |
| `server/outputs/<大学>.xlsx`、`.manifest.json`、`.current_state.json` | 各学院最近完成快照的当前汇总；新汇总有身份字段冲突时保留旧文件并记录 blocked |

大学当前汇总与本批版本分别审计：历史其它学院有冲突不会把一个清楚限定范围的新版本误称为全校成果。本批有失败、未完成或冲突仍阻断本批发布。重新采集同一学院替换其最新快照；同名不同主页保留，充分相同来源可去重并保留学院关联。

## 证据范围

`coverage.complete` 证明已核实计划分支的处理完整；`discovery_completeness=requires_independent_navigation_evidence` 明确不能由人数守恒推导全站入口发现完整。字段来源当前记录到候选/个人页及快照范围，尚未逐字段保存 DOM 路径。缓存导航指纹包含链接文字和 URL 的摘要，因此教师链接或文字变化也可能保守失效，并非最低 Token 策略。

空态侦察指令的更新改变契约摘要。永久库中的旧方案仍保留，旧契约不能直接当作新契约方案复用；未来工单可能需要重新侦察。本次只进行真实浏览器的本地页面回放和隔离测试，没有重排历史失败工单或请求付费模型，不能据此宣称先前法学系工单已完成。

当前验收集是 10 个合成结构、一个真实保存名录页的 60 固定身份、4 个恢复集成，另有 89 人完整真实快照通过 Playwright 拦截回放。湖南中医药大学目标入口实时访问仍连接关闭；湖南师范大学国际汉语文化学院已通过实时结构缓存复采，零模型调用，但 45 条页面观察有 14 组身份待复核，阻断交付。不能把保存页回放当成新一轮官网完整覆盖，也不能把页面观察数当成已确认人数。具体结果见 [实现审计](../audits/2026-09-27-verifiable-harvest.md)。

追加六个预先冻结的新学校随机学院真实测试，保留入口访问失败与无法证明完整名录的样本；发现完整正文范围和官网脚本污染等通用缺陷，修复前后独立核对身份、字段与正文。该轮由 Codex 学院子智能体浏览器侦察，没有请求 DeepSeek API，不能等同 Harness 自主侦察验收或全国适配率。见 [随机学院验证](../audits/2026-09-27-random-college-validation.md)。
