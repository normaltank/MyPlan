# 图片复核改选与批量保存

同一证据的图片用途决定可以覆盖更改，保存后仍提供全部选项。“用途未知或含文字”只表示未解决，不表示决定锁定。

图片用途卡片提供勾选、全选、取消选择及照片／用途未知两种批量保存。仅保存已勾选且由员工核对的项目；复用原逐项接口、当前证据和 CSRF 校验，不自动确认姓名、邮箱或身份。

逐项顺序保存，报告成功与失败数量；成功项取消勾选，失败项保留选择供重试。不会将部分失败写成全部成功。已保存决定可通过单项按钮或再次批量选择更改，证据变化仍由原接口拒绝。

回归覆盖真实浏览器勾选与部分失败重试、未选中项不提交、空选择不保存、批量保存后的单项改选，以及相同原件照片决定撤为未知后重新阻断。测试使用隔离材料，不代替员工处理真实复核。
