## 已复现问题

江西理工大学资源与环境工程学院任务 `ebd2991b7b474f18b2cc10cea22753f4` 的原审计 SHA256 为 `6e17a9210e3cc17184b8661a17df16c35b45984594a7313e67d3e118d9444bfc`。原件 `/info/1145/4520.htm`、`/info/1150/4633.htm` 的 `div.v_news_content` 无正文、媒体或隐藏简介，页面 `h2` 分别标识张春雷、贺建祥。旧逻辑在空容器时提前结束浏览器证明，保留整页给后续解析，可能把导航文字当简介。

## 实现及边界

`capture_profiles` 内部允许空容器继续执行原有请求、稳定 DOM、可见性与隐藏内容证明；侦察工具仍使用默认非空契约。`EmptyProfileEvidence` 在 `_scope_captured_profiles` 中核对本轮原件与所选主区摘要、目标与最终 URL、无截断边界、唯一候选、名录来源以及稳定可见的本人标题。仅这些证据成立时，完整空容器作为解析输入，官网简介留空；审计 `field_sources.empty_profile_evidence` 及 `missing_fields` 保存缺失原因。

正文范围沿用上游已经验证的完整 `profile_content_selector`；这不是单凭一个空 CSS 命中自行发现或证明全文范围。空后缀不等于全文缺失，未知 frame/媒体、错人/隐藏标题、重定向、来源缺失、摘要失效均不放行。已知为空但证据不成立的观察也仅使用空子树，防止回落导航；原始整页保留在快照，任务继续阻断。

此缺失证据不证明学院入口发现、分支、分页或人员完整，也不改变身份争议和其他交付门禁。字段缺失是明确观察，技术失败仍为失败。

## 两份原件回放及剩余边界

`.planning/review/empty-profile/replay.py` 使用原始名录解析候选、原始两份个人页，通过 `capture_profiles → _scope_captured_profiles → classify_candidates → harvest_candidates`。官网当前子资源按 URL 取得并归档，随后重放复用归档；未改原始 HTML，也未人工构造教师数据。结果及资源摘要位于 `.planning/review/empty-profile/replay-result.json`。

两页本轮证明均确认主区可见、稳定、网络空闲、标题匹配。官网 `/js/bdtxk1.js` 以裸 `function(e,t){` 开头，浏览器报 `Function statements require a function name`，本地独立语法检查也失败。该原始诊断保留在浏览器证据的 `page_errors`，并记录 `script_error_count`；沿用既有正文结构证明，单独的 pageerror 不等于正文仍未完成，不另增全站零脚本异常门槛。动态正文及未完成内容请求另有反例覆盖；实际影响主区的加载、资源或隐藏问题仍由现有门禁阻断。

最终两页均产生 `EmptyProfileEvidence`，提取两行简介为空，未解决项为空；审计状态 `browser_verified_empty_profile` 仅描述当前浏览器确认主区为空，不推断官网作者意图。未声称全院验收通过。

另观察到既有字段口径差距：原名录卡片仅有姓名，空正文不提供职称，现有解析管线仍默认输出“教师”。本增量仅修复空简介证据与导航回落，没有修改默认职称规则；两页全部字段准确性不能据此宣称验收完成。

这是“原始文档 + 已归档当前依赖”的本地浏览器回放，不是冻结版本后的未见学院验收，也不是新的官网全文采集。没有生产写入，没有推送或 CI 完成声明。
