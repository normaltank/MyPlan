# 案例库零散小项修复与复核

2026-10-08。局部修复四个问题，未修改宪法、侦察计划契约、资格口径或十列双 Sheet 结构。

## 姓名后任职标注

`FacultyCandidate.card_context` 已保留卡片原文，但此前资格审计只保存清洗后的姓名与主页。现将卡片原文写入持久审计的 `eligibility[].roster_context`，保留姓名链接内、链接外及跨链接断开的括号标注。姓名仍用于身份对应，任职标注不擅自改变资格规则。

江汉大学教育学院现网页只读回放得到 63 个姓名候选；5 个“兼任”标注完整保留。没有重新执行学院交付。回归覆盖三种链接边界和真实浏览器批量流程写出的审计 JSON。

## 拉丁字母姓名

原有姓名先验能识别少数英文全名，但名录分词将空格拆成单词，重音字母也未被支持。现在在切词之前保留完整拉丁字母段，允许 Unicode 拉丁字母、内部小写词、连字符和撇号；保留原有英文缩写识别。中文学历/职称文字界定姓名段终点，简介原文不裁剪。只有位于文字开头（可带“姓名：”标签）的拉丁字母段才算姓名位；中文简介中间的外文校名（如“王涛，……Universiti Teknologi Malaysia博士”）不会取代教师姓名。复核时用 164 个已存目录快照对比 main，唯一变化是曲靖师院新增 Muhammad Nadeem。

平顶山学院马拉加工程学院电气工程专业首页现网页回放得到 9/9 候选、0 项姓名复核，包括 5 个完整西班牙姓名。此结果仅验证姓名识别；其他分页、无名照片和图片个人页均未宣称验收通过。

## 浏览量接口 404

原来仅对永久缺失的脚本/样式作条件豁免。现在同样对 404/410 的 fetch/XHR 请求作结构核验：正文非空，服务器原始响应与浏览器中的正文文字和媒体引用一致，且可见性、DOM 稳定性与其余请求检查通过，才接受该个人页。没有按学校或接口路径加白名单。中止、5xx、未完成请求、浏览器生成的正文及正文内缺失图片仍然阻断。

湖南工商大学法学院一个真实个人页访问 `/index/flow` 返回 XHR 404；修复后 `confirmed=true`、`blocking_failed_request_count=0`。结构证明与完整页面分别保存在本地 `scratch/misc-case-fixes/hutb_verification.json` 和 `hutb_profile.html`。这不是全部 55 页或学院交付验收。

## 第四批 8 项邮箱复核

用户提供原交接 JSON；旧云端的 2026-10-02 页面快照未在本环境取得。本轮逐个使用真实浏览器访问其中 8 个官方个人页，均为 HTTP 200，再对核实的正文范围执行确定性回放。

- 楚雄 7 项：个人页明确使用“邮 箱”字段（空格/NBSP 及多个 inline 标签）。修复只让字段识别容忍字间排版空白，7 个邮箱均自动归属，完整正文回放无未解决项；任意昵称/个人邮箱仍不受姓名拼音限制。
- 闽江 1 项：两个地址都列在本人的 Email 字段中，保留双候选与原文。用户明确选择官网列在首位的地址；没有为生产账户伪造复核身份或重新入队历史任务。

逐项结果、原交接、当前页面哈希和用户选择保存在作者本地忽略目录 `scratch/misc-case-fixes/handovers/`，未提交。提交的 `email_batch4_contacts.json` 夹具对姓名、地址与主页脱敏，保留原始 DOM 标签、样式、拆分方式和空格结构。原始页面、真实字段和诊断脚本留在忽略目录 `scratch`。
