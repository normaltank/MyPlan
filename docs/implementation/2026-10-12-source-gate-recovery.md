# 随机探索首批来源门禁恢复

本工作项来自所有者的类型库维护目标及追加的“所有采集都失败，去修复”。业务契约以 [CONTEXT](../../CONTEXT.md) 为准；维护分类与发布条件见 [类型库流程](../architecture/type-library.md)。本项修改公共来源核验，不新增学院专用类型，也不把来源通过等同整院采齐。

## 复现与范围

基线为含 PR86 的 `419c892764b6f3e7c6846f9924ee8ec1d830bf98`。隔离运行从 Git archive 加载105个源文件，独立DB、队列、site-clock、dsh-home、输出与仅本机 Web；实际模块路径、模型deepseek-flash/high、提示词和配置摘要保存在该次run-manifest。日常服务与旧任务未改动。

[首批事先固定的10院与抽样框](type-maintenance-20261012/batch-001-selection.json)来自三所高校官方院系目录，seed为14114118251785040303。难采项未替换。本批是探索，不能用于阶段未见验收。

首批10院均在入口发现触及维护者设置的600000累计Token上限；尚无整院就绪交付。实际耗时658.047秒、247模型请求，非缓存输入253139、缓存输入5793920、输出166784 Token。按仓库2026-09-30价格配置估算USD0.31084602，provider账单与当前官网价格未核实。这一预算结束状态不是类型脚本已经运行并失败的证据。

浏览器已经保存真实官网名录。池州外国语学院`/szdw/yyx1.htm`仅在当前文档标题署名学院，logo无alt文字；选择可见页脚能取得学校。三明学院马克思主义学院`/smxyszb/js/list.htm`以完整“当前位置：师资队伍→教授”路径表达名录关系，标题仅“教授”；页脚学校学院文字可核对。页面外的计数/装饰变化还导致全HTML摘要在稳定见证读取间变化，拒绝了实际未变的名单、用途和归属区域。

原始失败运行完整保留在隔离冻结树`server/outputs/tasks/`及`recon-evidence/`；本次复现与新原件保存在本工作树`server/outputs/type-maintenance-20261012/diagnosis/`。这些受控材料在本机可读取；当前尚未形成跨环境完整原件归档，不据本文件宣称全部历史材料可达。

## 修改与边界

- 当前文档title以精确分段署名的学校/学院可作为当前官方页面机构证据；任意学校提及、职业经历、域名或错校署名不能代替。仍要求独立可见机构区域、不与正文重叠、当前用途关系、完整范围、真实浏览器证明。
- 当前用途见证明确含“当前位置”且末两项为同站师资父节点与职称分类、职称与本页标题相符时，承认其师资分组关系。侧栏、新闻/委员会、跨站父链接或单个职称词继续拒绝。
- 证明绑定最后保存的真实HTML，逐项比较实际名单、用途、机构区域、title身份与计数的稳定性；无关页外元素变化不单独拒绝。见证改变或来源/身份未证仍拒绝。
- 两次不同实际导航的失败材料按相同URL与正文选择器携带给既有复读规则。它不会把同页重复验证当两次访问，也不会直接忽略网络失败。模型收到范围问题和阻塞请求诊断；提示词指导保留未知而非无限重复改CSS。

这项公共流程发布以提交SHA、提示词SHA和运行manifest为精确版本。12项页面机制目录仍为原ID@1，本项未替换它们的处理器。计划缓存与来源复核合同已有`source_qualification.py`摘要依赖，源码更新后重新核验；旧运行、原件与结论保留。

真实三明原件形成[回归样本](../../tests/fixtures/source_rank_path/sanming_professors.html)。新增测试覆盖当前师资职称路径、错校、学校经历词、新闻/委员会、跨校与非当前页链接、正文假上下文，以及无关动态计数与最终原件SHA绑定。审查复现的外部样式隐藏、全页用途变化、晚到请求与复读收据均有拒绝或持久记录回归；无语义占位与Word装饰复用既有规则。最终新增22项和旧来源浏览器/诊断8项共30 passed，两轴只读复审无剩余发现；ruff先前通过，最后一次联网拉取因TLS失败，使用同版本缓存重新核对。完整CI、维护PR、同批新运行和历史影响结论尚未取得，持续补证，不预写通过。
