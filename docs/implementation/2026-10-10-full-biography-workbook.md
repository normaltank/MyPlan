# 完整长简介的工作簿存储

状态：实现并完成相关本地验证；尚未合并、加载到生产或完成资源学院实跑验收。

## 已复现的问题与修改

资源学院 `https://zh.jxust.edu.cn/info/1350/15702.htm` 的固定原件，在移除有明确 Word 目录证据的装饰后仍有 70,033 字符正文。Excel 单格容量限制使旧导出拒绝交付；截断简介或缩写均不满足完整原文要求。

`server/biography_workbook.py` 统一描述长简介的分段存储、人物关联、字符偏移及全文摘要。两个人员 Sheet 保持十列和一人一行；超长简介单元格链接到同一文件的“完整简介”Sheet。每段按 Unicode 字符边界切分，容量按 UTF-16 单元计算，保留换行与末尾空白。普通长度简介仍直接写原单元格，未增加附表。

原始 records/数据库简介仍为全文；主 Sheet 的显示提示只存在于导出副本。每次写完重新打开工作簿，逐段比对文字、归属和链接，并重组校验；通过后才原子替换目标文件。保存失败保留上个交付文件。采集文字始终写为文本，不作为公式执行。

浏览器同步读取实际文件并验证与记录绑定的 `biography_storage` 回执。队列在租约完成前要求回执与规范化记录一致；此处验证元数据，实际文件验证发生在同步入口，大学发布另生成并核验自己的文件。回执不是独立来源真实性或全院完整性证明；范围、身份和未解决项门禁保留。

保留既有导出对 XML 控制字符的清理规则，原始记录不变；不可表示的 Unicode 与其他字段超长继续报错。不能将导出成功解释为所有字段均有官网来源。
